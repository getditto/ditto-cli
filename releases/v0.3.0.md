# dittosh v0.3.0

This release adds support for the JavaScript and TypeScript agent skills added in
[agent-skills v0.6.0](https://github.com/getditto/agent-skills/releases/tag/v0.6.0),
and installs the skills a skill links to, so their links work. Use it with
[agent-skills v0.6.1](https://github.com/getditto/agent-skills/releases/tag/v0.6.1),
whose skills no longer link to files that installed copies don't include.

## New

`dittosh skills add` installs Ditto's new JavaScript and TypeScript skills:

- `js-sdk`: the shared JavaScript/TypeScript API guide.
- `js-node`, `js-web`, `js-react-native`, and `js-expo`: setup and
  troubleshooting for Node.js, browsers and React, React Native, and Expo.
- `native-app-config`: Apple and Android permissions and configuration, shared
  by the Swift, Kotlin, React Native, and Expo skills.

```bash
dittosh skills add js-sdk
```

`dittosh skills add` now installs companion skills: the other skills a skill
links to. Many skills link to files in other skills, such as
`../js-sdk/assets/runtime.ts`, and those links only work when both skills are
installed side by side.

- The CLI reads the links from the skill's files and follows them, so new
  upstream skill families work without a CLI update.
- With agent-skills v0.6.0 and later, any `js-*` skill installs the other four `js-*`
  skills and `native-app-config`. `swift-sdk` adds `native-app-config`.
  `data-streams` adds `kotlin-sdk`, `swift-sdk`, and `native-app-config`.
  `data-modeling` adds `write-dql`.
- A note on stderr lists the companions, and the results show them as
  `companion of <skill>`. Companions that are already installed show as
  `present` and don't count as skipped, including when OpenCode and
  Antigravity share `.agents/skills` in a project.
- `--no-deps` installs only the named skill. The choice is saved with the
  install, so later updates don't add companions to it either.
- Copilot and Windsurf get one flattened file per skill, so links can't work
  there. Companions are not installed for them.

`dittosh skills update` installs companions that a newer release adds. For
example, updating `swift-sdk` from v0.5.0 to v0.6.0 also installs
`native-app-config`. `update --no-deps` skips this for one run.

## Improved

- `dittosh skills add --agent` accepts the agent names used by `npx skills` as
  well as its own: `claude-code` (same as `claude`), `gemini-cli` (`gemini`),
  `github-copilot` (`copilot`), and `antigravity-cli` (`antigravity`).
- `dittosh skills update` reports a skill that the target release no longer
  ships as skipped, instead of failing the whole update.
- `dittosh skills update` against a release with no skills exits with code 2
  and a clear message.
- The exported tutorial (`dittosh tutorial`) shows how to install the
  JavaScript skills.

## Fixed

- `dittosh skills update --all` printed a garbled message when every skill was
  current. It now prints `all installed skills are already on <version>`.

## Installation and updates

Install with Homebrew:

```bash
brew install getditto/tap/dittosh
```

Update an existing install:

```bash
brew update && brew upgrade getditto/tap/dittosh
```

Then refresh your installed skills to agent-skills v0.6.1. The update also installs
any companion skills your installed skills now link to:

```bash
dittosh skills update --all
```

Supported systems: Apple Silicon macOS and Linux x64/arm64. Intel Macs are not
supported by the bundled Ditto SDK.
