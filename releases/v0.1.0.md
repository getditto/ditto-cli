# dittosh v0.1.0

The first Ditto CLI release provides an offline DQL workspace for exploring
Ditto, running queries and mutations, and working with built-in sample datasets.

## Included

- Interactive, file, stdin, and one-shot DQL execution.
- Table, JSON, CSV, Markdown, HTML, and vertical output, plus query diagnostics.
- Movies, retail, retail joins, and point-of-sale sample datasets.
- AI agent skill installation and package-manager-aware update commands.
- A built-in offline license; no account or user-provided credentials required.

## Installation and updates

```bash
npm install -g @dittolive/cli
npm install -g @dittolive/cli@latest

brew install getditto/tap/dittosh
brew update && brew upgrade dittosh
```

The command is `dittosh`. npm installation requires Node.js 22 or newer;
Homebrew manages Node.js 24. Supported systems are Apple Silicon macOS,
Linux x64/arm64, and Windows x64 (npm). Intel Macs are not supported by the
bundled Ditto SDK. Homebrew publication follows the GitHub/npm release in
the same workflow.

Run `dittosh version` to inspect the installed version and offline license
expiry. Run `dittosh update` to update through the detected package manager.
